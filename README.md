# 从军 · 查成分

《从军》（Enlisted）国服玩家的战绩成分分析页。输入昵称或 UID，拉最近 N 场战绩，
按 12 级分级表算总分、给风格标签和一段点评；测通 AI 之后，点评正文由 DeepSeek 按同一套数据重写。

**在线地址**：https://mp55c4.github.io/cj-search-your-xx/

## 怎么用

1. 打开上面的地址。
2. 第一次用要先给这个网页一把 DeepSeek 的 KEY（见下一节，只需一次）。
3. 粘贴玩家昵称或 UID → 开始分析。

## 配置 KEY（只需一次）

这个仓库**不内置任何 KEY**，源码是公开的，放进去等于公开。

第一次打开时，用带 `#k=` 的地址访问一次：

```
https://mp55c4.github.io/cj-search-your-xx/#k=sk-你的KEY
```

页面会把 KEY 存进**这台机器的浏览器**（localStorage），然后自动把地址栏里的
`#k=...` 抹掉。之后正常访问即可，不用再带。

> KEY 放在 `#` 后面，浏览器不会把它发给服务器，也不进访问日志。
> 换设备或清浏览器数据后需要再来一次。
> 想清除：浏览器 F12 → Application → Local Storage → 删掉 `cj_ai_key`。

## 数据来源

战绩数据来自 `cjapi.zhanhuo.com`，与本页无隶属关系；评价、分级、文案均为本地计算结果，
仅供参考，别当真。

## 说明

- 本目录（`线上版/`）由 `生成线上版.py` 从同目录的 `成分分析.html` 自动派生，
  **唯一区别是 `AI_CFG.key` 为空**。改逻辑请改主文件再重新生成，不要直接改 `index.html`。
- 单文件、无构建、无依赖，双击本地也能跑。
